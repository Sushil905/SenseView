02 / Pipeline

Model pipeline

Each block has one job, from face crops through session-level classification.

ViT-Base + LSTM + SVM
01 · FACE DETECTOR

RetinaFace

Detects and crops faces; five landmarks provide a rough yaw proxy for view ranking.

Optional dependency
02 · FRAME MODEL

ViT-Base / 16

Maps each face crop to a seven-expression score distribution. Fine-tune the frame model on RAF-DB.

224 × 224 input · 7 expression classes
03 · VIEW FUSION

Lowest absolute yaw

Selects the most frontal available camera view independently at every synchronized timestep.

Requires yaw for each view
04 · TEMPORAL MODEL

Bidirectional LSTM

Models the selected frame embeddings over time and returns per-timestep expression scores.
